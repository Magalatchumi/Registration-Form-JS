Registration Form

Project Description:
This is a simple Registration Form developed using HTML and JavaScript. The form validates user input in real time and enables the Submit button only when all fields are entered correctly.

Features:
• Name field should not be empty.
• Email should be in a valid format.
• Password should contain at least 6 characters.
• Error messages are displayed instantly.
• Submit button remains disabled until all fields are valid.

Technologies Used:
• HTML
• JavaScript

How It Works:
1. User enters Name, Email, and Password.
2. JavaScript checks each field while the user types.
3. Error messages are shown for invalid inputs.
4. The Submit button is enabled only when all validations are successful.

Outcome:
This project helps in understanding form validation, event handling, and DOM manipulation using JavaScript.
